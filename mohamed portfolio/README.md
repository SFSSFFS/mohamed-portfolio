# بورتفوليو بتمرير سينمائي

## التشغيل في VS Code
1. افتح مجلد `portfolio` عبر **File → Open Folder**.
2. ثبّت إضافة **Live Server** (Ritwick Dey).
3. انقر بزر الفأرة الأيمن على `index.html` ثم **Open with Live Server**.

## التعديل
- **النصوص:** في `index.html`. كل `<section class="chapter">` له `data-range="من,إلى"` (قيمتان بين 0 و1) يحدد متى يظهر أثناء التمرير.
- **البريد والروابط:** غيّر `you@example.com` ورابط GitHub.
- **الألوان:** المتغيرات في أعلى `style.css`، وألوان مراحل المشهد (غروب/نهار/ليل) في `STAGES` داخل `script.js`.
- **طول الرحلة:** `.spacer { height: 600vh }` في `style.css`.
- **اللغتان:** زر اللغة أعلى الصفحة يبدّل بين الإنجليزية والعربية ويحفظ اختيارك. النص الإنجليزي داخل العنصر والعربي في الخاصية `data-ar`. التخطيط ينعكس تلقائيًا في العربية. لتعديل نص عربي غيّر قيمة `data-ar`.

## استبدال المشهد بمشهدك ثلاثي الأبعاد
1. ارسم المشهد وحرّك الكاميرا في Blender (أو ولّده بأدوات الذكاء الاصطناعي) واحفظه فيديو `scene.mp4`.
2. حوّله إلى إطارات (150 إلى 300 إطار تكفي):
   ```bash
   mkdir frames
   ffmpeg -i scene.mp4 -vf "fps=24,scale=1600:-1" -c:v libwebp -quality 75 frames/frame_%04d.webp
   ```
3. افتح `script.js` وغيّر `frames: 0` إلى عدد الإطارات الفعلي، مثل `frames: 240`.

## النشر
اسحب المجلد كاملًا إلى Netlify Drop، أو ارفعه على GitHub ثم اربطه بـ Vercel أو GitHub Pages.

## تطوير لاحق
- تمرير أنعم: مكتبة **Lenis**.
- حركات أدق للنصوص: **GSAP + ScrollTrigger**.
- مشهد WebGL حقيقي: **Three.js** مع نموذج `.glb`.
